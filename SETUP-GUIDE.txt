GAMEVAULT SETUP GUIDE
=====================

This guide describes a generic Linux server + Windows gaming PC setup.

OVERVIEW
========

- Linux server stores game folders.
- Samba exposes the storage as an SMB share.
- Windows maps the SMB share as a drive, usually Z:.
- GameVault provides a LAN-only dashboard.

EXAMPLE VALUES
==============

Replace these with your own values:

- Server IP: <server-ip>
- SMB share name: games
- SMB user: <samba-user>
- Game storage root: /srv/gamevault/games
- Dashboard URL: http://<server-ip>:8080

LINUX SERVER SETUP
==================

1. Install packages:

   sudo apt update
   sudo apt install -y samba python3 pipx

2. Create the game storage directory:

   sudo mkdir -p /srv/gamevault/games/{steam,epic,pirated,savedata,setups}
   sudo chown -R <samba-user>:<samba-user> /srv/gamevault/games
   sudo chmod -R 775 /srv/gamevault/games

3. Create a Samba user:

   sudo adduser --disabled-password --gecos "" <samba-user>
   sudo smbpasswd -a <samba-user>

4. Add an SMB share to /etc/samba/smb.conf:

   [games]
      comment = Game Library
      path = /srv/gamevault/games
      browseable = yes
      writable = yes
      guest ok = no
      valid users = <samba-user>
      force user = <samba-user>
      create mask = 0664
      directory mask = 0775

5. Restart Samba:

   sudo systemctl restart smbd nmbd
   sudo systemctl enable smbd nmbd

6. Test locally:

   smbclient //localhost/games -U <samba-user>

WINDOWS SETUP
=============

Map the SMB share:

   net use Z: \\<server-ip>\games /user:<samba-user> <password> /persistent:yes

Or use File Explorer:

1. This PC > Map network drive
2. Drive: Z:
3. Folder: \\<server-ip>\games
4. Check "Reconnect at sign-in"
5. Enter Samba credentials

GAME FOLDER LAYOUT
==================

Use this layout on the SMB share:

   Z:\steam\<game>
   Z:\epic\<game>
   Z:\pirated\<game>
   Z:\savedata\
   Z:\setups\

GameVault scans steam, epic, and pirated as game source folders.
Savedata and setups are utilities, not counted as games.

GAMEVAULT SERVICE
=================

Recommended local env file: /etc/gamevault.env

   GAMEVAULT_HOST=<server-ip>
   GAMEVAULT_PORT=8080
   GAMEVAULT_GAME_ROOT=/srv/gamevault/games
   GAMEVAULT_SMB_HOST=<server-ip>
   GAMEVAULT_SMB_SHARE=games
   GAMEVAULT_HOME=/opt/gamevault
   GAMEVAULT_HTML_FILE=/opt/gamevault/index.html
   GAMEVAULT_LOG_FILE=/var/log/gamevault/transfer.log
   GAMEVAULT_EPIC_ROOT=/srv/gamevault/games/epic
   GAMEVAULT_EPIC_LOG=/var/log/gamevault/epic-install.log
   GAMEVAULT_EPIC_STATE=/var/lib/gamevault/epic-state.json
   GAMEVAULT_LEGENDARY=/root/.local/bin/legendary

Example systemd service:

   [Unit]
   Description=GameVault Dashboard
   After=network.target smbd.service

   [Service]
   EnvironmentFile=/etc/gamevault.env
   WorkingDirectory=/opt/gamevault
   ExecStart=/usr/bin/python3 /opt/gamevault/server.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target

Start it:

   sudo systemctl daemon-reload
   sudo systemctl enable --now gamevault

EPIC DOWNLOADER
===============

Install Legendary:

   python3 -m pipx install legendary-gl

Login from the dashboard:

1. Open https://legendary.gl/epiclogin
2. Login with Epic
3. Copy authorizationCode
4. Paste in the dashboard

Epic games download to the configured epic folder, usually:

   /srv/gamevault/games/epic

TROUBLESHOOTING
===============

SMB not accessible:

   net use
   ping <server-ip>
   net use Z: /delete
   net use Z: \\<server-ip>\games /user:<samba-user> <password>

Access denied:

   sudo pdbedit -L
   sudo smbpasswd <samba-user>
   ls -la /srv/gamevault/games

Slow transfer:

- Prefer wired Ethernet over WiFi.
- Check NIC speed with ethtool.
- Check router/switch port speed.
- Use a gigabit adapter for large game libraries.

Steam does not detect a copied game:

1. Close Steam.
2. Put the folder in the correct local Steam library folder.
3. Reopen Steam.
4. Start install to the same folder so Steam discovers existing files.

SECURITY
========

- Keep GameVault LAN-only.
- Bind dashboard to a LAN IP.
- Firewall SMB and dashboard ports to LAN only.
- Never commit passwords, local IPs, logs, runtime state, or private config.
